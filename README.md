# ConectaPro

Prototipo navegable de web informativa, registro, campañas y seguimiento de leads.

## Qué incluye

- `index.html`: web informativa pública con explicación del producto y llamadas a crear un espacio.
- `registro.html`: alta inicial del espacio de trabajo.
- `login.html`: acceso al espacio existente.
- `backoffice.html`: resumen operativo con campañas, canales y bandeja vacía de leads. La vista de campañas permanece dentro del backoffice y conserva el menú lateral.
- `sitio.html`: sitio web público del negocio, alimentado con los datos del registro.
- `ser-distribuidor.html`: plantilla de captación basada en la página existente de myorygn.es, con vídeo, formulario y enlaces configurables de email y WhatsApp.
- `alternativa.html`: galería de campañas, preparación para redes y gestión inicial de leads.
- `landing.html`: landing pública del negocio, con propuesta de valor, CTA y formulario de captación.
- `index.html`: primera propuesta de onboarding paso a paso, conservada para comparar.
- Galería de piezas, selección de red, copia de texto y estados vacíos claros.
- Configurador de URL personal por usuario desde el backoffice (`?ref=...`).
- Campaña IGNYT con tres piezas visuales aportadas por el usuario y textos de invitación a conocer el producto.
- Responsive para escritorio y móvil.

Es una interfaz de validación. El registro y el acceso funcionan en el navegador mediante almacenamiento local; las conexiones con redes sociales, WhatsApp, almacenamiento de leads y autenticación real todavía no están activas.
